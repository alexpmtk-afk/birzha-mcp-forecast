# G2 — зафиксированная карточка будущего пилота (coord-20261017-02)

**Статус:** PROJECT PREREGISTERED DESIGN; NOT STARTED; owner consent for unattended live capture/deployment NOT GIVEN. Веточный PR #259 — research-only. Это будущий сбор доказательств, не доказанный Forecast Engine и не рекомендации сделок.

## Одно предположение

В новых данных **согласованная направленная структура D1 и H1** может чаще совпадать с направлением изменения цены через 5/10/20 торговых сессий, чем простое продолжение недавнего движения. Это проверяемая гипотеза без предполагаемой выгоды или выбора весов. Ранее рассмотренные 30 дат — только контекст разработки, **никаких коэффициентов из них не подбирать**.

## Даты наблюдения и рынки (заморозить до первого события)

Время каждого наблюдения: **13:10:00 по Москве (Europe/Moscow UTC+03:00)**. Ровно двенадцать заранее перечисленных кандидатов:
**20.10, 22.10, 26.10, 28.10, 30.10, 03.11, 05.11, 09.11, 11.11, 13.11, 17.11, 19.11.2026**.
Если по точному рынку дата не торговая, сессия изменена или источник отсутствует, записать `NOT_TRADING / SOURCE_UNAVAILABLE / NO_EVIDENCE`; дату **не заменять** следующей удобной датой. Это максимум 72 заранее определённых рынок×T0, итоговая пригодность может быть намного меньше. Сдвига автоматического на день нет.

Исходные корни **шести рынков**: SBER акция `TQBR`; IMOEX индекс (не фьючерс); RTSI индекс (не RI); Si, BR, GOLD — **только точные торгуемые фьючерсные SECID**. Алгоритм выбора фьючерса, применяемый до получения исходов: из текущего реестра MOEX на T0 выбрать контракт соответствующего базового актива, допущенный к торгам данного дня, с подтверждённым `last_trade_date` позже двадцатой будущей торговой сессии от T0; из них максимальный объём **предыдущей полностью завершённой сессии**; равенство → лексикографический SECID. Любой неопределённый календарь, отсутствие инструмента, объёма или точного даты истечения = `ABSTAIN_CONTRACT_UNRESOLVED` без последующей подстановки. В каждом событии зафиксировать точный `SECID/board/engine/market`, правила selection и все проверенные кандидаты до исхода. Контракты не «склеивать» по экспирациям. Допустимость индекса VOLUME отдельно; отсутствие объёма для индекса означает `NOT_APPLICABLE`, не отказ по самой структуре.

## Источники и момент T0

Использовать только последние **полностью закрытые и уже полученные к 13:10** D1 и H1 одного точного SECID, каждый с не менее **50** свечами в исходной хронологии, без искусственных вставок/пересчёта цен. Нужны оригинальные MOEX ISS raw bytes + SHA каждого ответа, original `completed`, `begin/end`, `available_at` (отдельно с confidence), реальное `observed_at` при первом получении, source request URL и source scope. Отсутствие первого получения или точной сессии → `ABSTAIN_PIT_NOT_ATTESTED` (в исследовательском пилоте может быть сохранено событие диагностического отказа, но не прогноз). Рабочий нулевой уровень — только V2 строгая функция, **никакой** `build_reconstructed_market_structure_facts` для будущих прогнозов.

Сразу при первом допустимом наблюдении зафиксировать snapshot JSON, SHA256, UTC/МСК T0, exact version Git SHA, source receipt checksums, причину отбора и прогноз/ABSTAIN **до первого будущего исхода**. Записывать в отдельную непроизводственную папку одним файлом на слот: `G2_STRUCTURE_PILOT_V1/<YYYYMMDD>T131000+0300/<MARKET>/<SECID>.json` с exclusive create / no replacement, защитой от повторного содержимого и SHA256 manifest. Git commit и исходная последовательность сохраняются, но **Git SHA/time само по себе не независимая TSA или полная PIT-аттестация**. Реальный capture требует отдельно разрешённого внешнего пути и проверки времени.

## Жёстко зафиксированное правило результата на T0

На каждой паре фактов `confirmed_price_structure`:
- D1=`HH_HL` и H1=`HH_HL` → **UP**.
- D1=`LH_LL` и H1=`LH_LL` → **DOWN**.
- Иначе (MIXED, не хватает экстремумов, H1/время/инструмент не допущены) → **ABSTAIN** с кодом причины. Приоритет отказа: источник/время/SECID → OHLC/история → структура.
- Порогов score/вероятности/весов **нет**. Длина pivot 2 слева + 2 справа, окно 50, V2 ATR14 Wilder, median20 остаются неизменны. Относительный объём **записывается как контекст, но не фильтрует направление**.
- Для определённой направленности отдельно зафиксировать простую непроверенную величину: `P_forecast(H) = P0 + sign * ATR_D1_price * sqrt(H)` для H∈{5,10,20}, где `P0` — последняя допустимая на T0 D1 close. Это **методологическая гипотеза**, не калиброванное ожидание прибыли. Если ABSTAIN — числового прогноза нет.

## Ориентиры на тех же наблюдениях

- **Неизменная цена**: `P_flat(H)=P0`.
- **Простая инерция**: `r5=P0 / D1_close_5_completed_sessions_ago - 1`; `P_momentum(H)=P0*(1+r5*H/5)`; знак `r5` — ориентир направления (при r5=0 — без направления). Пять сессий — заранее установленная длина, не выбор по известным исходам.
- Фиксировать ориентиры на **каждом исходном наблюдении, где известен P0**, и отдельно сравнивать ошибки кандидата с обоими на точном пересечении **только случаев, где кандидат выдал UP/DOWN**. Не считать ABSTAIN точным нулевым прогнозом, не скрывать долю отказов.

## Проверка исходов (после будущих горизонтов)

Для каждой допустимой H∈{5,10,20} использовать **H-ю фактическую полностью закрытую торговую сессию** точного SECID после T0, с заранее аттестованным календарём. `actual_return=(P_H/P0-1)*100`. Направление: UP>0, DOWN<0, FLAT=0 без доп. порога. В отдельном результате: первая достигнутая граница `P0±1×ATR_D1_price`, `UP_FIRST/DOWN_FIRST/NEITHER/AMBIGUOUS`, только при сохранённой последовательности внутренняя свеча→M1→trades; при неизвестном порядке отмечать AMBIGUOUS, не угадывать. Несозревшие H20 = `PENDING_MATURITY`, экспирация или неточный SECID = `UNRESOLVED_CONTRACT`, недоступные свечи = `MISSING_OUTCOME`, источник может отказаться.

Отчёт по заранее определённым максимум 72 случаям: **coverage** UP/DOWN/ABSTAIN по рынкам и датам, direction hit/miss на разрешённом пересечении и Wilson 95% доверительный интервал, paired MAE для прогноза/flat/momentum на тех же исходах, сравнение со знаком инерции (paired wins/losses/ties), первое касание + неопределённые порядки; статусы и причины недоступности отдельно, не уменьшать знаменатель незаметно. Для 10–12 T0 и нескольких горизонтов результаты коррелированы; **не делать выводов о статистически доказанной точности или финансовой пользе**.
