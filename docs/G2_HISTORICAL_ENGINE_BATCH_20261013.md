# Пакетное исследование существующего ценового движка

## Задача и границы

Три связанные задачи: расчёт по списку исторических дат, отдельная оценка
сохранённых прогнозов, сводка по каждому рынку и сроку. Основа — исправление
коллеги #229, версия `3f8ac504cbb5c900c872497fe8959e10bc13f191`.
Существующие движок, параметры, сборщики источника и журналы не изменены.

Это восстановленное исследование на открытом для разработки периоде
2021–2022. Нормализованный вход не удостоверяет поставщика или время первого
получения. Контрольные суммы связывают точные байты файлов, а не доказывают
подлинность источника. Платные потоки не используются. Будущие цены
зарезервированного периода 2023–2024 не допускаются. Историческая запись в
рабочем журнале не создаётся, разрешение выпуска остаётся закрытым.

## Два отдельных действия

Сначала программа читает только исходные контексты и сохраняет неизменяемый
файл результатов существующего ценового движка. В этом файле будущих цен нет.
Затем другая команда читает уже сохранённый файл и отдельный набор будущих
свечей. Она не пересчитывает и не меняет прежние прогнозы. Это технический
порядок восстановленного исследования, а не доказательство настоящего
прогноза, выпущенного в прошлом до будущего события.

Из корня репозитория, с установленным пакетом либо `PYTHONPATH=src`:

```powershell
python -m scripts.g2_historical_engine_batch freeze --bundle inputs.json --bundle-sha256 <SHA256> --output predictions.json
python -m scripts.g2_historical_engine_batch assess --predictions predictions.json --predictions-sha256 <SHA256> --future-bundle future.json --future-sha256 <SHA256> --output assessment.json
```

Команды сообщают контрольную сумму созданного файла. Все выходные файлы должны
быть новыми в существующей папке. Существующий файл, каталог или символическая
ссылка не заменяются. Результат вычисляется полностью до публикации одним
действием без замены; поздняя коллизия имени также отвергается.

## Входной формат

Общий объект: `schema`, `scope`, `cases`; дополнительных полей нет.
`scope=RECONSTRUCTED_HISTORICAL_PRICE_ENGINE_ONLY`.
Не более 1000 контекстов и 64 МиБ на файл. Повторные ключи JSON,
нечисловые бесконечные значения и несовпадающая внешняя контрольная сумма
отвергаются. Пустой список будущих контекстов разрешён, пустой исходный — нет.

Для исходных контекстов `schema=G2_PRICE_REPLAY_INPUT_BUNDLE_V1`:

- `case_id`: уникальная строка из букв, цифр, точки, подчёркивания и дефиса;
- `instrument`: сериализованный `Instrument`, включая точный контракт,
  площадку и возможности данных;
- `cutoff_at`: время границы расчёта;
- `series`: ровно `D1`, `H1`, `M15`, каждое — список сериализованных `Candle`.
  Пустой список означает отсутствие данных, не нулевую цену.

Каждая свеча явно содержит open/close/high/low/volume/value/begin/end/completed.
Дополнительные поля допустимы только из действующего Candle. Переданные
утверждения EXACT о доступности не принимаются: в восстановленном контексте
доступность остаётся UNKNOWN. Прогнозный адаптер #229 проверяет цены,
длительности, порядок, отсутствие перекрытий и отсечение по границе времени.
Повтор одной пары рынок/контракт/граница не увеличивает число наблюдений.

Для будущих контекстов `schema=G2_PRICE_REPLAY_FUTURE_BUNDLE_V1`:

- `case_id`: ссылка на сохранённый исходный контекст;
- `instrument`: тот же рынок и контракт;
- `expected_session_dates`: 20 различных упорядоченных дат внутри 2021–2022;
- `candles`: полные будущие D1-свечи, допускается только префикс указанного
  календаря. Отсутствующие поздние сроки остаются неизвестными.

Официальность переданного календаря независимо не удостоверена. Контекст
другого контракта, неизвестный номер прогноза, пропуск или незавершённая
будущая свеча не принимаются. Отсутствие будущего контекста оставляет все
сроки ожидающими. Отсутствие исходных свечей сохраняет отказ от расчёта.

## Что считается

Результат содержит отдельные строки и 18 сводок: 6 рынков × 3 срока.
Направление оценивается только по направленным прогнозам; «всегда рост» —
на тех же строках. Нейтральные прогнозы показаны отдельно. Числовая ошибка
и ориентир неизменной цены считаются на одной парной выборке. Пустая выборка
даёт null, а не 0% точности. Показаны исходы, ожидания и отказы из-за данных.
Пересекающиеся горизонты не объявляются независимыми наблюдениями.

Это оценка конечной цены через 5/10/20 сессий. Первое касание уровня,
торговая прибыль, независимое преимущество, официальный календарь и рабочая
установка этим блоком не подтверждаются.

## Проверки

Шесть искусственных полных контекстов проходят через настоящий ценовой
движок и обе отдельные команды. Проверяются неизменность сохранённого файла,
частичные исходы, отсутствие свечей, нейтральные решения, правильные
знаменатели, внешние суммы и внутренние пломбы, повтор/перекрытие свечей,
смена контракта, запрещённый период и поздняя коллизия выходного имени.
Настоящий архив 2021–2022 содержит только дневные свечи; пакетный запуск
на нём должен показать отказ из-за H1/M15, не рыночную точность.
