# G2 — факты реакции цены на зафиксированные уровни

## Основа и назначение

Зависимая ветка от #155 `0a55a9607642cd1428a396c9d69ff404c7d0578f`.
Свежий main и открытые изменения сверены. Файлы веб-коллеги не меняются.
Требования E07/E08/E11 предусматривают заранее известные уровни и завершённую
последовательность OHLC. Правила закрепления, отказа и ложного пробоя пока
не приняты. Реализован отдельный фактологический слой без таких оценок.

## Что считает

Для девяти источников уровня из Forecast Record V3: включает ли диапазон
свечи цену уровня; есть ли максимум выше/минимум ниже; положение закрытия
ABOVE/ON/BELOW; смена стороны между двумя соседними закрытиями вне уровня;
возврат на сторону первого закрытия вне уровня после закрытия с другой стороны.
Закрытие точно на уровне не относится к покупателям или продавцам.
Сравнения точные, без произвольного допуска. Счётчик контактов — число свечей,
а не независимые тесты уровня и не оценка его силы. Не устанавливается порядок
движений внутри свечи, поэтому выход и возврат внутри одной свечи не объявляются
ложным пробоем. Смена стороны закрытия не объявляется непрерывным пересечением
при возможном ценовом разрыве.

## Причинность и границы

Принимается прежний неизменённый прогноз V3 с типизированными источниками,
точный тот же символ/SECID и явно переданные более поздние свечи D1/H1/M15.
Начало свечи не раньше фиксации уровня, конец позже фиксации и не позже
момента наблюдения. Нельзя проверять исторические касания по уровню,
рассчитанному в конце той же исторической последовательности.
Все OHLC конечны и согласованы, свечи завершены, времена упорядочены,
дубли/пересечения запрещены. Время доступности требуется EXACT/DOCUMENTED,
получение и момент наблюдения — с явным часовым поясом;
end <= available_at <= observed_at <= observation_at. Неизвестное или
предположенное время получения закрывает весь расчёт, будущие строки не
отбрасываются молча. Часы свечей без пояса следуют московской конвенции снимка.
Все времена — свидетельства во входных данных, без независимой подписи.

Окно явно задаётся входным набором, до 5000 свечей. Непрерывность торгового
календаря не доказана; пропуски не превращаются в удержание. Нет наблюдений —
NULL и причина; известное отсутствие контактов в переданных свечах — ноль.
Приблизительность исходного профиля сохраняется. Прогноз/Outcome не меняются.
Этот слой не влияет на направление, вероятность, уровень силы или Control.

## Хранение и использование

Отчёт LEVEL_REACTION_FACTS_V1 связывает исходный forecast_id и полный SHA256
прогноза, снимок, SHA256 свечей, точный контракт, момент наблюдения и все факты.
Отдельный SQLite журнал добавляет отчёты; идентичный повтор идемпотентен,
другой момент наблюдения создаёт другую запись. Один forecast_id нельзя
связать с другим содержимым; изменение сохранённых байтов выявляется при чтении.
Это новый отдельный журнал наблюдений, не production DuckDB.

```powershell
python scripts/g2_level_reaction.py --forecast forecast.json --candles candles.json --observation-at 2026-03-02T14:00:00+03:00 --journal reactions.sqlite3 --format text
```

Вход candles.json имеет форму CandleSeries.to_dict() с отдельными completed,
available_at, available_at_confidence, observed_at для каждой свечи. Без
--journal команда только читает и выводит результат. --format json сохраняет
машиночитаемую форму. --format text даёт короткую русскую таблицу и ограничения.
Входы не перезаписываются; повторяющиеся поля JSON запрещены. Изменения
боевого контура/объединение отсутствуют. Реальная независимая приёмка не заявлена.
