# Сводка фактических данных и исходных решений по шести рынкам

Точная основа #175: 8d938e7e5ee65364baf442d404f276c5559b634b.
Модуль `six_market_report.py`, команда `scripts/g2_six_market_report.py`.
Версия `SIX_MARKET_FACTS_V1`. Не меняет прогнозы, хранилище и будущие исходы.

## Что показывает

Фиксированный порядок SBER / Si / BR / GOLD / IMOEX / RTSI. Для каждого:
точный контракт, момент исходной записи, фактические числа свечей D1/H1/M15,
допуск изменения за 5/10/20 шагов, сохранённое решение и причины отказа,
опорная цена и наличие отдельно переданных поздних наблюдений.
У каждого рынка сохранён полный подробный отчёт с происхождением уровней,
полными причинами недоступности и хешами исходных снимка/прогноза.

Число свечей в снимке не доказывает пригодность всех показателей и полноту
независимого календаря. Отсутствующие файлы рынка не становятся нулём или
отказом прогноза. Отсутствие поздних входов не означает, что сбор сломан.
При переданном расписании его пропуски отличаются от отсутствия расписания;
серии закрытий сохраняют существующий отказ, касания — supplied bars only.

Один общий T0 показывается только при наличии всех шести входов и точном
совпадении времён; иначе времена сохранены раздельно. Режим явно задан:
OFFLINE_RESEARCH_REPEAT либо FROZEN_RECORD_VIEW. Оба режима не удостоверяют
выпуск или receipt. Нет совокупного торгового сигнала или оценки точности.

## Вход и команда

Пересчитывает дочерние отчёты из оригинальных снимков/записей/наблюдений,
не принимает готовые неподтверждённые отчёты. Любой несовместимый переданный
вход отклоняет сводку, а не маскируется отсутствующим рынком.

```json
{
  "version": "SIX_MARKET_REPORT_INPUTS_V1",
  "evidence_mode": "OFFLINE_RESEARCH_REPEAT",
  "markets": [
    {"market": "SBER", "snapshot": "SBER/snapshot.json", "forecast": "SBER/forecast.json"}
  ]
}
```

Необязательные поля элемента: candles, observation_at, schedule, как у
команды одного рынка. Пути относительны каталогу перечня; абсолютные пути
и выход за его каталог отвергаются. Повторяющиеся поля JSON, рынки и
неизвестные поля отвергаются. Максимум шесть элементов. Недостающие рынки
явно отмечаются. Команда только читает файлы, не пишет в базу или сеть.

```sh
python scripts/g2_six_market_report.py --manifest manifest.json --format text
```

Во всех шести примерах окна изменения 5/10/20 допущены, отказов исходного
прогноза нет. Последующих наблюдений в этих входах нет; их не выдумывали.
Повтор сводки совпал, SHA двенадцати оригинальных файлов сохранены,
настоящая команда дала тот же результат. Локальные файлы
../six-market-facts-summary; перечень ../six-market-original-inputs.json.

Искусственные проверки отдельно покрывают отсутствующий рынок, короткую
историю, неизвестное качество при достаточном числе свечей, разные T0,
подмену рынка/снимка, отсутствие расписания, пропуски, неизвестные поля,
дубли, пути вне каталога, неизменность исходников и обе формы команды.
Независимая приёмка и рабочая установка остаются отдельными.
