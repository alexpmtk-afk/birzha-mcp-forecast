# G2 — фактическое положение цены

Зависимая основа: #163, 977b615c7bc8da9174a21c9057b9c2952a0d452f.
E05 в карте оставляет правила LOCATION/AT_POC и допуск неформализованными.
PRICE_LOCATION_FACTS_V1 поэтому сравнивает точные исходные цены, без допуска,
назначения силы, маршрута или полного LOCATION. ForecastRecord не меняется.

## Правила

Опорная цена выбирается M15 → H1 → D1 по первому не-NULL last_close, как
существующий производитель. Выбранная цена обязана иметь конечное значение,
согласованный период/счётчик, допущенное качество и latest_completed_end ≤ T0.
Некорректный выбранный источник закрывает весь отчёт сравнения: скрытого
отката к старой цене нет. Требуется версия полных окон и согласованная
округлённая normalized current_price; сравнения сохраняют сырую точность цены.
Для одного закрытия допустим только явно объяснённый недостаток общего окна.

Девять источников уровней проходят прежний build_price_level_evidence.
Для каждого сохраняются исходный метод, период, время, статус точности и
причина исключения. ABOVE/BELOW обозначают сторону УРОВНЯ относительно цены.
ON — только точное равенство исходных чисел, не AT_POC. Выше выбирается
минимальная цена, ниже максимальная; совпавшие источники не теряются.
Отсутствие уровня на стороне даёт NULL, точные совпадения отдельно.

Расстояние со знаком = уровень − опорная цена; процент = расстояние /
abs(опорной цены) × 100. При нулевой цене процент NULL с причиной.
Расстояние в единицах дневных колебаний требует отдельно допущенного D1 с
15 завершёнными свечами, положительного простого ATR14 и согласованного
normalized масштаба. Нет масштаба → NULL только для этой метрики;
расстояние в цене сохраняется. Переполнение конечных чисел → NULL с причиной,
геометрический порядок сохраняется. NaN/Infinity в снимке отвергаются при
формировании идентичности, не получают пригодную подпись.

Отчёт связан с полным снимком snapshot_id и SHA256; собственный report_id
зависит от содержимого и правил. Подлинность времени получения исходных
данных не удостоверяется модулем: это ответственность вызывающего контура.
Время завершения не равно доказанному времени получения. Данные в снимке
не дополняются и не перезаписываются, журнал исходов не затрагивается.

## Запуск

```powershell
python scripts/g2_price_location.py --snapshot snapshot.json --format text
```

Вход — полный сохранённый MarketSnapshot.to_dict() с явным MARKET_SNAPSHOT_V2.
Повторяющиеся поля и изменённая схема запрещены; вложенные профиль/поток и
качество восстанавливаются без потери содержания. Команда только читает и
выводит русский отчёт или JSON, сеть и рабочую установку не использует.
Программный вход: build_price_location_report(snapshot).

Результат не является доказательством точности прогноза, приёмкой реальных
источников или установкой в рабочий контур. Формализация полного LOCATION и
правил AT_POC остаётся отдельной задачей карты.
