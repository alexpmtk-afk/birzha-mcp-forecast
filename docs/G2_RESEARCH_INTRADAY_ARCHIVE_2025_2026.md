# Отдельный исследовательский архив H1/M15 2025–2026

Статус: исследовательский Draft. Он не развёрнут и не содержит реальную историческую базу.
Рабочий архив D1, HOME, main, Google Sheets и Forecast V1 не меняются.

## Цель

Один локальный DuckDB-архив для повторного тестирования любых версий Forecast
на одинаковых H1/M15 свечах шести рынков: SBER, Si, BR, GOLD, IMOEX, RTSI.
Жёсткий диапазон по московскому календарю: 2025-01-01..2026-12-31.
Данные 2024 и более ранние, как и 2027+, не входят в этот архив.
Исследования D1 за 2021–2022 годы продолжаются отдельно.

## Уже подготовлено в коде

- Отдельный ResearchIntradayArchive. Прежде чем открывать существующую DuckDB
  для записи, программа читает её только в режиме READ ONLY и убеждается,
  что это именно обозначенный исследовательский архив; чужую базу не меняет.
- Ключ свечи: точный SECID + таймфрейм + начало. Повторная запись тех же
  цен не создаёт дубликатов. Противоречивая запись отклоняет транзакцию.
- M15 получает данные из 15 завершённых нативных минутных свечей. Если
  недостаёт минуты или обнаружен повтор, весь неполный квартал исключается.
  Отсутствие сделок тоже способно вызвать пропуск, поэтому это политика
  осторожной проверки, а не гарантия полного рыночного покрытия.
- Минутные исходные M1 используются только временно. На диск сохраняются
  готовые H1 и M15, не массив M1.
- Для фьючерсов сохраняется точный SECID; слепое склеивание разных контрактов
  в одну ценовую последовательность не допускается.
- Источник — существующий MOEX ISS клиент с его ограничителем обращений.

## Три режима, один торговый день

По умолчанию PLAN: без сети, без открытия базы.

~~~bash
python -m scripts.g2_intraday_research_archive --date 2025-06-09
~~~

PROBE: только однодневная выборка по шести рынкам. Возвращает число нативных
часовых и минутных свечей, собранных M15 и обнаруженных неполных интервалов.
База не создаётся.

~~~bash
python -m scripts.g2_intraday_research_archive --mode probe --date 2025-06-09
~~~

INGEST: пробная запись только в явно выбранный отдельный файл, после
подтверждения возможности получения источника.

~~~bash
python -m scripts.g2_intraday_research_archive --mode ingest --date 2025-06-09 --markets SBER --archive ./research/birzha_intraday_research_2025_2026.duckdb --ack-research-write
~~~

Папка research должна существовать заранее. Никогда не использовать путь
рабочей DuckDB. Имя архива проверяется автоматически.

## Остаётся до полноценного заполнения за два года

Реальное наличие M1/H1 на MOEX в 2025–2026 годах **ещё не доказано**.
Проверки GitHub работают на искусственных свечах, а не на биржевой выгрузке.
Нужно подтвердить глубину источника и полноту биржевых сессий; составить
историческую карту SECID фьючерсов и оценить объём; дополнить дневные
контрольные точки независимой проверкой календаря и отчётом о недостающих
датах для двухлетнего backfill. Для дней, по которым источник дал ненулевые H1/M15 без выявленных
пропусков, сохраняется отметка получения с привязкой к точному SECID.
Повторный запуск той же даты пропускает H1/M1 и не создаёт дубли.
Если замечены короткие часовые бары или неполные четверти часа, сохраняется
отдельное качество CAPTURED_WITH_GAPS: это не PASS полноты. Такая дата также
не скачивается бесконечно повторно. Только явный параметр --retry-partial
дозапрашивает её, сохраняя запрет на конфликтующие изменения цен.
Эта отметка НЕ удостоверяет независимую полноту биржевой сессии и PIT.
До этого весь двухлетний архив автоматически не загружается.

Исторический момент первого получения данных не подтверждён (PIT unknown),
полученные сведения предназначены для офлайн-исследований, не для
ретроспективной выдачи «настоящих прогнозов». NO_TRADE / RELEASE_BLOCKED.
Права на массовое получение и использование информации MOEX требуется
проверить перед большим архивным сбором.


## Фактическая ограниченная проверка MOEX от 13.10.2026

Запуск Github Actions на хостируемом runner (только пробное чтение, без записи):
https://github.com/alexpmtk-afk/birzha-mcp-forecast/actions/runs/38436092957

Для SBER за 2025-06-09 MOEX ответил: 16 часовых H1 после строгой проверки;
992 минутные M1 в памяти; 64 полные M15, полученные из M1. Остались
5 неполных по минутному составу четвертей часа и 2 нестандартных по
длительности часовых бара. Код возвращает PARTIAL_NOT_FULLY_VERIFIED
и завершает строгий источник с кодом 1; **наличие самих данных подтверждено**,
но полный OHLCV-контекст всех сессий не подтверждён. Не следует считать
недостающие интервалы провалом источника: возможно, это крайние сокращённые
отрезки торгов либо минуты без сделок. Отдельно нужна проверка против
реального session calendar. Это не проверка всех 2025–2026 дат и других рынков.

Особенно важно: существующий LIVE-сборщик Forecast V1 допускает агрегацию
M15 даже из неполного набора минут, тогда как данный отдельный
исследовательский архив сознательно сохраняет только строгие полные M15.
Поэтому этот архив в текущем виде служит сравнительным качественным
набором, **ещё не гарантирующим идентичный replay существующего Forecast V1**.
Для честного сравнения разных версий потребуется отдельный контракт
политики агрегации и качества M15, не подменяющий эти отличия.

Сделан отдельный read-only опрос MOEX ISS через hosted GitHub Actions:

Дата 2025-06-09, сохранение на диск отключено.

| --- | --- | ---: | ---: | ---: | ---: | ---: |
| SBER | SBER | 16 | 992 | 64 | 5 | 2 |
| Si | SiM5 | 16 | 866 | 54 | 7 | 0 |
| BR | BRN5 | 16 | 868 | 54 | 7 | 0 |
| GOLD | GDM5 | 16 | 869 | 55 | 6 | 0 |
| IMOEX | IMOEX | 9 | 532 | 34 | 3 | 1 |
| RTSI | RTSI | 9 | 532 | 34 | 3 | 1 |

Источник возвратил данные по всем шести рынкам на проверенную дату.
При этом каждый рынок имеет предупреждение о нестандартных или неполных
интервалах под строгой политикой: поэтому probing workflow завершился
кодом 1 (PARTIAL_NOT_FULLY_VERIFIED). Это НЕ означает ошибку сетевого
доступа или отсутствующие вообще архивы. Две даты/года целиком не
проверены, полнота биржевых сессий не сертифицирована.
