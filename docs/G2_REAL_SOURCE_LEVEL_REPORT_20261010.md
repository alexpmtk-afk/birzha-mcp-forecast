# Проверка связанного отчёта на реальных сохранённых ценах

Основа #167 c5b815dd59dd226caf288aeb387b172911fefd4c.
Новая процедура G2_OFFLINE_REAL_SOURCE_LEVEL_REPORT_V1 только читает архив
оригинальных публичных MOEX ISS ответов и создаёт отдельные файлы результата.
Никакой сети, выпуска в журнал, Outcome, HOME или изменения старых прогнозов.

## Формат и ограничения

Первый сохранённый шестирыночный выпуск использует ForecastRecord V1 и
NORMALIZED_FEATURES_V1. Он не совместим с V3-отчётом и не обновляется молча.
Вместо этого построены новые исследовательские V3-расчёты по нынешним правилам,
с T0=явное время отдельного анализа. OFFLINE_REPEAT_NOT_ORIGINAL_ISSUANCE.
Это реальные сохранённые цены, не прежние prospective forecasts, не текущие
котировки и не доказательство точности. Раздел после T0 отсутствует: будущие
свечи и искусственное расписание не добавлялись. Подлинность часов поставщика
и полнота междневного календаря независимо не удостоверены.

## Проверка входов

Точный SHA256 всего архива, оригинальные SHA всех страниц, полное множество
шести рынков, точные SECID/возможности CANDLES, уникальные имена/привязки страниц,
полнота оригинального capture, строки/колонки JSON, интервалы получения и
завершённые OHLC. Архив читается из тех же проверенных байтов; пути с каталогами,
повторяющиеся поля и избыточный архив отвергаются. Всего 31 файл, 30 страниц.
M15 собирается только из полных упорядоченных 15×M1; исключения записаны отдельно.
NormalizedFeatureEngine получает реальные возможности каждого инструмента:
индексам не приписываются объём/открытые позиции. Выход только в новую папку,
повторная запись поверх существующего результата запрещена.

Первый положительный искусственный тест не объявлял CANDLES: расчёт правильно
закрыл цену. Исправлено только объявление возможности в синтетическом примере,
добавлен явный отрицательный тест отсутствия возможности. Защита не ослаблялась.
