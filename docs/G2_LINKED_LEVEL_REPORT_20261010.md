# Единый отчёт цены, уровней и последующих наблюдений

Зависимая основа #165: 4b51c92879de9a59cd808a6635ba860f6f861fa6.
Версия LINKED_LEVEL_FACTS_V1. Это связанный фактический вид E05/E07/E08,
не новые универсальные правила LOCATION, acceptance, holding power или CONTROL.

## Связь источников

Передаются оригинальный полный экспорт MarketSnapshot V2 и сохранённый
ForecastRecord V3. Обязательны совпадение snapshot_id, symbol, точного SECID,
строки T0 и версии снимка. Все девять origin-объектов уровней должны точно
совпасть с повторным допуском уровней из этого снимка. Если опорная цена
допущена, значение сохранённого reference_price должно совпасть без подмены
типа/точности. Снимок, прогноз и источники не изменяются.

Полное пересоздание направленной оценки/параметров прогноза не выполняется:
этот отчёт проверяет общие исходные факты и их содержательную связь, а не
аутентичность выпуска или подлинность всего ForecastRecord. SHA256 исходного
прогноза и полного снимка, идентичности трёх отчётов и подписи наблюдений
сохраняются. Подлинность получения снимка и внешнего расписания — отдельная
ответственность вызывающего контура. Сам SHA256 не удостоверяет поставщика.

## Два разных времени

Раздел «При записи прогноза» использует только исходный снимок и неизменяемые
уровни. Раздел «После записи прогноза» повторно строится из отдельно переданных
завершённых OHLC с точным инструментом, известным временем доступности/получения
и явным observation_at позже T0. Эти будущие относительно прогноза свечи
никогда не становятся его исходными входами. Новое наблюдение меняет итоговый
report_id, но сохраняет at_t0 и подпись прогноза.

Без последующих свечей получается полезный отчёт только положения при T0.
Если свечи переданы, явный срок наблюдения обязателен. При отсутствующем
расписании, пропуске или лишней свече серии закрытий недоступны; факты касаний
и смен стороны остаются только фактами переданных наблюдений, не доказанной
непрерывной торговой последовательностью. Отсутствующие числа не равны нулю.
Приблизительный свечной профиль видимо помечен; все совпавшие источники уровня
сохраняются. Сила, контроль, маршрут и торговые цели не назначаются.

## Запуск

```powershell
python scripts/g2_linked_level_report.py --snapshot snapshot.json --forecast forecast.json
python scripts/g2_linked_level_report.py --snapshot snapshot.json --forecast forecast.json --candles candles.json --observation-at 2026-03-02T14:00:00+03:00 --schedule schedule.json --format text
```

По умолчанию — понятный русский отчёт, --format json — полные машинные факты.
Команда только читает файлы и печатает результат; сеть, журнал/базу данных,
рабочую установку и исходные файлы не изменяет. Дубли полей JSON запрещены,
счётчик экспорта свечей проверяется. Источники форматов — документы #165/#163.

Проверки: несовпадение снимка/инструмента/T0/версии/цены/источников уровней,
позднее получение и незавершённые свечи, пропуски/нет расписания, приблизительный
профиль, короткая история, неизменность всех файлов, два настоящих запуска
команды (русский текст и JSON), независимость раздела T0 от последующих цен.
Это проверка работы программы; точность прогноза здесь не измеряется.
