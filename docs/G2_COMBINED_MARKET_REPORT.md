# Единый отчёт движения и реакций на уровни

Зависимая основа: #171, точный 16edfb353332cdf22aa8b5be28ab58fd676acfc7.
Это отдельное представление фактов, без изменений Forecast Record, Outcome,
хранилища, выпуска прогнозов или рабочей установки.

## Что показывает

1. При записи прогноза: изменение за 5/10/20 шагов дневного, часового и
   пятнадцатиминутного периода. Попарное совпадение/расхождение знаков,
   время последних завершённых свечей и причины недоступности.
2. При записи прогноза: исходная цена, девять источников уровней, ближайшие
   выше/ниже, расстояния и допуск каждого источника.
3. Отдельно после записи: касания по диапазону свечи, смены стороны закрытия,
   возвраты и серии закрытий относительно тех же зафиксированных уровней.

Отсутствие поздних свечей оставляет третий раздел без наблюдений. Без
объявленного расписания либо при пропуске/лишней свече серии недоступны;
касания относятся только к переданным свечам. Время между закрытиями не
является непрерывным пребыванием цены на стороне уровня.

## Связь исходных данных

`build_combined_market_report` пересчитывает оба дочерних отчёта из одного
снимка, проверяет одинаковые идентификатор/полный хеш/версию снимка,
инструмент/точный контракт/T0. Исходный прогноз проверяется существующим
связанным модулем, включая точное происхождение всех девяти уровней.
Поздние свечи никогда не передаются расчёту движения при T0.
Версия `COMBINED_MARKET_FACTS_V1`; идентификатор — SHA256 всего содержания
без самого идентификатора, включая оба дочерних отчёта и момент наблюдения.
Это согласованность содержания, а не подпись поставщика или удостоверение
времени получения. Расписание требует отдельной проверки подлинности.

## Команда

```sh
python scripts/g2_combined_market_report.py --snapshot snapshot.json --forecast forecast.json
python scripts/g2_combined_market_report.py --snapshot snapshot.json --forecast forecast.json --candles later.json --observation-at 2026-03-02T14:00:00+03:00 --schedule schedule.json --format json
```

Читает исходные выгрузки один раз, проверяет повторяющиеся поля и заявленное
число свечей. Подготовленные непроверенные отчёты не являются входом.
Выход — русская таблица либо структурированное представление; записи на
диск/в базу и сетевых запросов нет.

## Выполненные проверки

Местные проверки охватывают неизменность входных файлов, связь снимка и
прогноза, изменение только поздней части при смене поздних цен/момента
наблюдения, запрет незавершённых/чужих/поздно полученных свечей, пропуски
расписания и настоящую команду в обеих формах.

На том же сохранённом архиве шести рынков, SHA256
`83f37b4cb48c456c21a39feb71403336294882de8acdf81b2cfb442998637659`,
получены шесть одинаково повторяемых отчётов; снимки и исходные записи
не менялись. Это прежний исследовательский повтор #169 с сохранёнными
ценами 09.10.2026, а не новый выпуск, текущие котировки или измерение
точности. Поздних наблюдений для этих шести примеров нет; они не выдуманы.
Поздний раздел показан отдельно на явно искусственном примере.
