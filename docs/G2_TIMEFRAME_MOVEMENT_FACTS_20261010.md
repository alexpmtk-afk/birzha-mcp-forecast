## Контракт

Сравниваются существующие return5/10/20: last / close_n_steps_ago − 1.
Для каждого периода и каждого окна отдельно требуется6/11/21 завершённая
свеча, версия полных окон, согласованные период/число/качество и завершение
не позже T0. Допустим только явный общий дефицит истории; иные причины
ухудшения закрывают метрику. Версия снимка MARKET_SNAPSHOT_V2 обязательна.
Непригодное одно окно не стирает пригодные короткие окна или другие периоды.

Направление для этой процентной формулы допускается только при конечной
положительной последней цене и return > −1: тогда положительная начальная
цена согласована с формулой. При неположительных/неизвестных ценах направление
недоступно; исходная последняя цена сохраняется, не превращается в missing/0.
Это ограничение именно вывода направления из ratio, не запрет нулевых цен
в остальных модулях. Точный ноль — EXACTLY_FLAT, без округления или допуска.
Небольшое положительное/отрицательное значение сохраняет свой знак.

Для каждого окна три пары: одинаковый знак, противоположные ненулевые знаки,
один точный ноль или недоступность. При отсутствии одного периода пригодная
пара остальных сохраняется, общий подсчёт по3периодам и общие признаки NULL.
Пять дневных свечей и пять часовых имеют разную длительность. Последние
моменты завершения каждого периода видимы; это не доказательство синхронного
начала/конца или общей календарной полноты. Подлинность получения не доказана
по одному времени завершения. Доверие к заявленным версии/снимку отдельно.

Отчёт связан с snapshot_id и полной SHA256 снимка; собственная идентичность
зависит от всех входных фактов/правил. Исходный снимок и прогноз не меняются.
Команда scripts/g2_timeframe_movement.py --snapshot snapshot.json принимает
полный экспорт. Необязательный --forecast forecast.json дополнительно связывает
по правилам #167 исходный прогноз и уровни. --format text/json; только чтение.
