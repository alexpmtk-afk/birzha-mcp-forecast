## Что реализовано вместе

1. Return5/10/20 и SMA20/50: точные последние6/11/21/20/50 закрытий.
   Незавершённое, отсутствующее, неконечное, bool/string значение закрывает
   содержащий его признак. Строка остаётся в окне; более старой не подменяется.
2. ATR14 остаётся mean14 True Range по15 полным корректным HLC свечам,
   а не Wilder. Неверная геометрия/неполнота/переполнение/нулевой масштаб
   закрывают вход. Нормировка на abs(last close) даёт положительный масштаб
   также при отрицательной цене. Для положительных нормальных цен формула прежняя.
3. ER20 требует21 закрытие. Нулевой путь недоступен, а ненулевой возврат даёт0.
   Равные цена/средние и нулевое движение больше не добавляют ложный отрицательный
   trend_score; это изменение старой эвристики явно версионировано, не новый классификатор.
4. Volume ratio требует текущий объём и20 предыдущих известных неотрицательных
   объёмов. Нулевой текущий объём допустим; отсутствующий не подменяется нулём.
   Нулевой/неконечный baseline недоступен. Отсутствующий объём не портит цену.
5. Нормировка отвергает некорректные числа, нулевой/отрицательный масштаб и
   переполнение. SnapshotService передаёт точный Instrument для capability guard.
   Нет CANDLES/VOLUME/TRADESTATS/OI capability → соответствующие normalized значения
   отсутствуют. Причины остаются в MarketState: NOT_APPLICABLE отличается от UNAVAILABLE.
   Непроверенный источник flow закрывается; будущий прогноз использует допущенные
   delta/OI из normalized, поэтому сырые неподдерживаемые значения не добавляют вес.
6. MarketState новой версии требует15/20/21 свечу по признаку вместо общего50.
   Общий DataQualityContract и его обзорная оценка50 не переписаны.
   Ослабление применяется только при явных причинах недостаточного прогрева;
   неизвестное качество или иной дефект не обходятся. Proxy profile сохраняет H1 guard50.
   Старый normalized V1 сохраняет прежнее представление MarketState/guard50.
7. Prediction новой версии явно сообщает D1_SMA_TR14_PRICE_V1; численная формула
   и коэффициент границ не заменены Wilder. Отдельная версия Prediction входит
   в идентификатор. Неконечные цена/масштаб/границы отвергаются.
8. Нулевая граница support/resistance не заменяется другим периодом через
   проверку истинности числа: выбирается именно наличие значения.

## Версии и история

TIMEFRAME_FULL_WINDOWS_SMA_TR14_V2 — кодовые правила расчёта.
NORMALIZED_FEATURES_V2_FULL_WINDOWS_SMA_TR14 — значение существующего поля version
в новых serialized normalized features. Поле/формат TimeframeState не расширяются.
MARKET_STATE_VECTOR_V1_PER_FEATURE — новые правила допуска.
BIRZHA_FORECAST_BASELINE_V0_5_FULL_WINDOWS — новая версия инженерного прогноза.
PREDICTION_CONTRACT_V2_SMA_TR14_FULL_WINDOWS — честно обозначенные новые границы.

Dataclass default normalized V1 сохранён для старых объектов; новая версия
назначается вычисляющим engine. Старые Forecast Records, Prediction payloads,
источники, исторические квитанции и отпечатки не переписываются.
Нельзя считать старую ошибочную надпись Wilder исправленной задним числом.
Новым прогнозам нужен новый snapshot_id/engine_version/contract_id.

## Границы результата

Не реализуется Wilder seed/сглаживание: это отдельная версия и решение P04.
Не заменяются direct displacement/W20 исследовательского #136 старым return/ATR.
Подсчёт20/21 строк сам по себе не доказывает торговый календарь, доступность к T0,
точный контракт или полный период. Эти доказательства остаются у upstream
Snapshot/StoredMarketData/sequence contracts. Удалённые upstream строки этот слой
не восстанавливает. Общая карточка G2-DATA-FIXES не объявляется закрытой.
Метод и длина Profile не переопределяются, новые прогнозные пороги не вводятся.

instrument=None оставлен для совместимости прямого численного API; применять
к нему доказательство capabilities нельзя. Рабочий SnapshotService всегда передаёт
Instrument. Ручной повреждённый snapshot с NaN не получает канонического идентификатора:
он отвергается, а не молча очищается с сохранением старого отпечатка.
Не заявляются улучшение точности, независимая приёмка, REAL MOEX/HOME установка.
Веб-файлы source/capture/frozen/outcome/bridge/renderer не изменяются.
