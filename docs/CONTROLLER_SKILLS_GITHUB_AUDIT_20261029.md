## Установка навыков
Каноническая редакция новых навыков хранится в этой Git-ветке; до отдельного merge она не является частью main.
Проектный AGENTS.md подключает оба навыка по условию задачи. Локальные копии в рабочей области владельца сверяются по SHA256, без копирования приватных отчётов в Git.
При изменении навыка сначала править выбранную Git-ветку, проверять, затем обновлять локальные копии с проверкой хешей. Не редактировать копии независимо.
Обычный ChatGPT не получает локальные навыки автоматически. Ему требуется доступное поручение/файл, а статус передачи должен быть подтверждён.
