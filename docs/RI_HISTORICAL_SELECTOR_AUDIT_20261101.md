Основа: main 9fb5feec5f64b5be7d86d9947b4676f7e5d741b5. HOME остаётся на этой версии; установка исправления не выполнялась.

## Причины и исправление

1. Внешнее имя инструмента/семейство SECID — RI, официальный ASSETCODE — RTS. Прежний код ошибочно отбрасывал эти строки при загрузке истории, общей проверке кандидатов и создании Instrument. Добавлено единое соответствие, исходные поля не переименовываются. Сохранена совместимость с явно обозначенными старыми исследовательскими строками ASSETCODE=RI.
2. Официальные дальние контракты могут иметь VOLUME=NULL и NUMTRADES=0. Такие строки теперь исключаются как доказанно неторговавшиеся; NULL не заменяется нулём. Неизвестное число сделок, положительное число сделок и неизвестный объём всё ещё блокируют выбор.

Единый селектор T−1, правило максимального положительного объёма, срок окончания обращения, детерминированный выбор при равенстве и запрет текущего объёма сохранены. Правила текущей ликвидности не подставляются.
