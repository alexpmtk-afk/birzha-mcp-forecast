## Единственная процедура

Параметры CENTER = Q75(absD20),Q75(ER20),Q25(absD20),Q25(ER20),Q50(W20).
Каждый рынок весит1/6; каждая его строка1/(6*n). Квантиль: минимальное
наблюдаемое значение с накопленным рациональным весом >=p/100, без интерполяции.
Десять соседей: один из пяти квантильных уровней +/-10 процентных пунктов.
Фиксированные ID CENTER,DT_MINUS,DT_PLUS,ET_MINUS,ET_PLUS,DB_MINUS,DB_PLUS,
EB_MINUS,EB_PLUS,WB_MINUS,WB_PLUS. Максимум11 классификаций, без второго
поиска или смены критерия после результата.

Пороговый эталон: absD20>=центрального dT даёт знакD20, иначеUNKNOWN.
Классы и доли, серии/переключения, сравнения с соседями/эталоном — по
шести рынкам и отдельно2021/2022. Серии связаны только одним SECID и
перекрывающимися точными окнами. Исключения не смешиваются сUNKNOWN.
Все параметры/отпечатки сохранить до классификации; внешний отпечаток
квитанции подготовки записать отдельным файлом вне её каталога до оценки.

Исследовательский экран: все соседи допустимы, максимальное расхождение
CENTER/сосед <=20% всех принятых строк каждого рынка. ТолькоCENTER,
никакого лучшего соседа. Дегенеративный класс, пустой содержательный союз,
непригодные параметры или отсутствие устойчивости дают отсутствие выбора;
не заменятьNULLнулём. Годовые сравнения описательные, не новый критерий.
Внутренняя ошибка — ABORTED; неполная запись без квитанции не принимается.

Отдельным прямым вычислением проверить квантили, параметры11кандидатов,
метки всех принятых строк каждого кандидата, полноту и порядок строк,

исследовательский экран. Это дополнительная проверка исполнителя,
не независимая приёмка другим человеком.

никакие реальные строки по этому признаку не исключать.

читаемую сводку. Отрицательный итог допустим. Не менять правила и не
