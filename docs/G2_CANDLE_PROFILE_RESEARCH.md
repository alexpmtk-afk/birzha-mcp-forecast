# Отдельное исследование приблизительного объёмного профиля

Точная основа #179 1097e67ae240b797e9e7d62e276745dc0bb4294d.
Новая версия CANDLE_PROFILE_RESEARCH_V1, общий результат
SIX_MARKET_CANDLE_PROFILE_RESEARCH_V1. Ни старые снимки, ни прогнозы
не обновляются. Расчёт не выпускает новый прогноз и не меняет Outcome.

## Окно и правила допуска

Последние 50 переданных H1-свечей точного инструмента, без удаления
ошибочных строк или подстановки более старых. Требуется объявленная
возможность CANDLES/VOLUME, 50 строк, ordered unique nonoverlapping
интервалы, явные часовые пояса, завершённые свечи, корректные конечные
OHLC и неотрицательные конечные объёмы. Избранные строки должны иметь
end ≤ observed_at ≤ source_observed_at ≤ analysis_at.
Отсутствующий объём не становится нулём. Известный нулевой объём остаётся
нулём и не уменьшает число строк; окно без положительного объёма закрыто.
Любая непригодная выбранная строка закрывает расчёт всего окна.
Неканонические числовые значения, даты, дубль/перестановка источника и
будущее получение отвергаются. Переполнение/некорректный результат
закрывают профиль, а не возвращают бесконечные ориентиры.

При наличии отдельного объявленного расписания проверяются его
инструмент, время получения, окно и совпадение свечей; пропуск/лишняя
свеча закрывают профиль. Без него расчёт допускается только как
приближение по последним 50 ПЕРЕДАННЫМ свечам. Самостоятельная полнота
торгового календаря остаётся неизвестной, это явно подписано.

## Метод и происхождение

Метод CANDLE_TYPICAL_PRICE_VOLUME_PROXY_V1: весь объём одной свечи отнесён
к типичной цене (high+low+close)/3, 24 корзины, область70процентов объёма.
Повторно используется существующий VolumeProfileEngine, но строгая
обёртка предотвращает молчаливое исключение непригодных строк.
Это не распределение реальных сделок по ценам, не точный торговый профиль
и не доказанная сила/роль уровня. Поведение самого прежнего помощника
profile_from_candles не меняется.

Сохраняются полный хеш исходного ряда, хеш выбранных 50 строк, точный
инструмент/возможности/единицы, первый/последний интервал, объявленное
время получения, время исследования, метод/параметры и причина недопуска.
Общий результат связан с хешами исходного архива, manifest и оригинальных
H1-страниц. Само содержание receipt не является независимой подписью
поставщика. Это исследовательский повтор после получения сохранённого
архива, а не исторический прогноз, выданный до тех данных.

## Команда

```sh
python scripts/g2_candle_profile_research.py --archive source.zip --archive-sha256 SHA256 --analysis-at 2026-10-10T20:04:40Z --format text
```

Читает исходный архив с точным хешем, проверяет inventory/page hashes,
времена захвата и точные контракты; разбор идёт во временном каталоге.
Не пишет в исходники, журнал или рабочую базу, не обращается к бирже.
Режим JSON содержит полный паспорт. Нет замены ранее сохранённых
Forecast Records: профиль — самостоятельный новый исследовательский
результат.

## Проверки и собственная исправленная ошибка

Искусственные случаи: короткое окно, неизвестные/непригодные/нулевые
объёмы, незавершённость, даты получения/часовые пояса, дубли/порядок,
ограничения инструмента, отсутствие/пропуски расписания, переполнение,
изменение вне выбранного окна, полный хеш и неизменность источника,
коррупция исходного архива и настоящая команда обеих форм.

Первый местный запуск:2failed/60passed. Моя ошибка примера — позиционный
конструктор Candle поменял ожидаемые value/volume местами; расчёт читал
volume правильно. Исправлен пример именованными аргументами, повтор
62passed. Это не проблема биржи, не изменение формулы и не повреждение
источника. Задержка инструментов местного чтения обойдена разрешённым
запуском с явным рабочим каталогом, без перезапуска компьютера/программ.
Независимая приёмка, календарь, получение, преимущество модели и рабочая
установка остаются отдельно.
