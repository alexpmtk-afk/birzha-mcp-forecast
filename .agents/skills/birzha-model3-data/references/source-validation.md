# Проверка источников
- Подтверждать контракт/рынок/доску/единицы/шаг цены. Не склеивать контракты без принятого правила.
- Гражданская дата не равна торговой сессии. Не выводить календарь только из свечей.
- Отсутствующая минута может означать отсутствие сделок, перерыв, потерю выгрузки или неизвестность. Проверить семантику; ни нули, ни обязательные 15 строк для любого M15 не вводить автоматически.
- Проверять агрегаты OHLCV, сессии, полноту страниц, дубли/пропуски. Нестандартный end не доказывает незавершённость исторического бара.
- Нулевой оборот не считать подтверждённым денежным объёмом без документации; хранить исходное значение и статус отдельно.
- M1 OHLCV не восстанавливает фактического инициатора и точный объём каждой цены. Нужны сделки/проверенное распределение; проверить доступность и условия источника.
- Закрытие, публикация, первое получение и расчёт — разные времена. Поздняя загрузка не доказывает доступность в прошлом.
- Экстремум хранит время события и подтверждения; D1 на H1-решении уже закрыт/доступен. Будущий профиль или будущие бары запрещены во входе.
- Недостаток истории/настройки/данных — пробел, не ноль. Наличие файла не заменяет чтение.
